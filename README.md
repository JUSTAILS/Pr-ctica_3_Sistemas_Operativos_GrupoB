# Pr-ctica_3_Sistemas_Operativos_GrupoB

#Este proyecto tiene como objetivo comprender y aplicar los conceptos fundamentales de la creación y gestión de procesos en sistemas operativos tipo Unix mediante el lenguaje de programación C.
#Se implementan y analizan diferentes funciones del sistema —como fork(), exec(), y system()— que permiten la creación, ejecución y control de procesos padre e hijo.
#Cada ejercicio demuestra un aspecto clave de la administración de procesos: desde la generación básica de procesos, hasta la ejecución de programas externos y la observación de comportamientos especiales como los procesos huérfanos y zombies.
